# Homes Protector - Home Improvement & Remodeling Landing Page

A high-converting, mobile-responsive landing page designed for **Homes Protector**, offering estimates for roofing, siding, windows, kitchens, bathrooms, flooring, and HVAC services.

---

## 🚀 Live Demo & Deployment

This repository is designed to be hosted directly on **GitHub Pages**.

- **URL:** `https://<your-username>.github.io/homesprotector/`

---

## 📁 Repository Structure

```text
homesprotector/
├── index.html     # Main landing page with estimate form & services overview
├── thanks.html    # Success redirection page after form submission
└── README.md      # Documentation for project structure and setup
```

---

## 🛠️ Features

- **Responsive Design**: Fully optimized for Desktop, Tablet, and Mobile devices.
- **Form Integration**: Integrated with [FormSubmit.app](https://formsubmit.app) endpoint (`3k97w52fa8`).
- **Smooth Navigation**: Jump directly to sections (Services, About, FAQ, Estimate).
- **Interactive Form Pre-fill**: Clicking any service automatically populates the form's service selector.
- **Branded Aesthetics**: Custom SVG shield logo branding with clean navy (`#142b3b`) and orange (`#f2a23a`) theme colors.

---

## ⚙️ How to Deploy on GitHub Pages

1. Commit and push `index.html`, `thanks.html`, and `README.md` to the `main` branch of your repository.
2. Navigate to **Settings** > **Pages** in your GitHub repository.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Set the branch to `main` / `root` and click **Save**.
5. Your site will be live within a few minutes!
